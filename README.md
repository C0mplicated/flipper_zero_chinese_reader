# Flipper Zero Chinese Reader — Novel Reader 0.4 Final

[English](README.en.md) | 简体中文

当前暂定最终版。在用户确认第三版运行良好的基础上，仅将选书列表里的 TXT 默认问号图标
换成与应用一致的书本图标，并更新版本标识。字体、排版、缓存、背光及书签格式均沿用第三版。

面向 Momentum Dev `d3f89dfe (18.08.26)` 的中文 TXT 阅读器。

## 从第三版更新（读卡器）

先关闭 Flipper，取卡连接 Windows。备份并替换这一个文件：

- `apps/Tools/novel_reader.fap`

已有第二版字库不需要替换。不要删除自己的 books 文件夹和 `.nrpos` 阅读进度文件。
安全弹出读卡器，装卡开机。选书列表应显示小书本图标；按 OK 打开阅读菜单，顶部应显示 `Reader 0.4 Final`。
第四版沿用第三版索引和书签格式，已有有效索引可以继续复用。
回退时恢复备份的 `.fap` 即可，已有版本 ZIP 保持不变。

第三版已加入每书持久分页索引、书本应用图标、背光设置和设置保存。
保留原生 12×12 点阵汉字、标点换行和紧凑段落。阅读翻页按键不变，菜单改为上下选择。

## 安装：不需要编译，也不需要重刷固件

1. 解压 ZIP。退出 Flipper 正在运行的应用，用 USB 连接电脑。
2. 使用 qFlipper 的文件管理功能，或关机后用读卡器操作 microSD。
3. 把包内 `sdcard` 文件夹的**内容**复制到 SD 卡根目录，保留层级。
   若已有同名文件，请先备份，只复制本项目相关文件，不要替换整个 apps 文件夹。
4. 最终位置应为：
   - `/ext/apps/Tools/novel_reader.fap`
   - `/ext/apps_data/novel_reader/font12.bin`
   - `/ext/apps_data/novel_reader/books/sample.txt`
   `/ext` 是设备中 SD 卡的路径，不要在 SD 卡上额外创建 ext 文件夹。
5. 在设备中打开 Apps → Tools → Novel Reader，选择 sample.txt。
6. 测试正常后，把自己的 UTF-8 `.txt` 小说放进 books 文件夹。

若菜单里找不到应用，可在设备文件浏览器中直接打开该 `.fap`。

## 操作

| 按键 | 阅读中 |
|---|---|
| 上 / 下 | 上一页 / 下一页；支持按住重复翻页 |
| 左 / 右 | 后退 / 前进五页 |
| OK | 打开设置菜单 |
| Back | 保存并返回选书；选书界面返回退出 |
| 长按 Back | 关闭当前书籍 |

菜单中：上下选择项目，左右或 OK 调整背光/反色；其余项目按 OK 执行。
Back 返回正文，长按 Back 关闭书籍。

| 菜单项目 | 功能 |
|---|---|
| Backlight: Auto | 跟随系统，默认选项 |
| Backlight: Always on | 阅读期间常亮，使用系统原有亮度 |
| Backlight: Off | 阅读期间关闭背光，按键唤醒也使用零亮度；需要环境光阅读 |
| Invert | 反色显示 |
| First page | 回到第一页 |
| Rebuild index | 手动重新生成当前书籍索引，完成后恢复当前位置 |
| Return to book | 关闭菜单 |

背光和反色设置自动保存到 `apps_data/novel_reader/settings.bin`。
离开阅读界面回到选书或正常退出应用时，释放常亮锁，并恢复之前的系统亮度与自动控制。
选书及首次索引时使用系统背光控制。没有修改系统通知设置文件或系统自动锁定选项。
突然崩溃无法保证执行退出恢复；如亮度未恢复，重启设备会重新加载原系统设置。
进度在成功翻页后及退出书籍时保存。页脚百分比按页数计算。

## 这一版的范围与限制

- 12×12 单色中文，每行最多 10 个全角字，4 行正文；英文固定 6 像素布局。
- 支持 UTF-8、有或无 BOM、LF/CRLF。GBK/UTF-16 请先在电脑上另存为 UTF-8。
- 支持非空、最大 64 MiB TXT。EPUB/PDF 不支持。
- 首次打开、手动重建或缓存失效时建立 SD 卡页码索引，大文件仍可能需要等待；按 Back 取消。
  成功后每本书旁保存 `.nridx`，以后打开复用。取消或中断留下的未完成索引不予使用。
  取消后若出现提示，松开或再按 Back 返回。
- 实际字体包含 30,399 个非 ASCII 原生点阵字形，使用 65,536 个固定字形槽位，文件约 1.5 MiB。
  简繁体和常用标点可用；不是所有 Unicode 汉字都支持，缺字和补充平面字符显示方框。
- 字体在 SD 卡，程序只缓存当前页面字形；4 KiB 文本缓存，不把全文加载进 RAM。
- 支持常见中文标点避行首、前引号避行尾，并处理跨页边界；原文强制换行及超长标点串不保证避头尾。
  仍未实现英文整词换行、ASCII 直引号的开闭判断、章节识别、字号调整、搜索和电量显示。
  紧凑排版默认启用，暂不提供保留空行的开关，不适合依赖空白布局的诗歌或代码。
- 系统选书界面的中文文件名显示由固件决定；建议先使用英文文件名。
- 每本小说旁会生成 `<书名>.txt.nrpos` 续读文件和 `<书名>.txt.nridx` 分页索引。
  174,279 页的索引约 681 KiB。第一、二版的 `session.idx` 不再使用，无需手动处理。
- 复用前核对文件大小、布局版本、索引长度和书籍开头/中部/末尾各最多 4 KiB 的指纹。
  这是快速抽样而非全文校验：相同大小、抽样区域之外的编辑无法保证发现。
  替换或编辑小说后，建议手动 Rebuild index 或删除对应 `.nridx`。
- 修改小说后建议删除对应 `.nrpos`，避免恢复到旧位置；同大小内容替换目前无法自动识别。
- 写入书签失败会显示错误，但断电瞬间不保证保存完成。不会修改小说原文。
- Off 模式临时调整通知服务内存中的背光亮度以避免翻页亮灯；只适配本包锁定的 Momentum SDK。

## Windows 重新编译（可选）

安装 Git for Windows。将项目放在如 `C:\Flipper\novel-reader` 的普通目录。
在这个目录打开 PowerShell，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-windows.ps1
```

此参数仅用于本次 PowerShell 进程，不修改系统永久执行策略。组织策略禁止脚本时请遵循组织规定。
脚本下载锁定的 Momentum 源码、子模块和官方构建工具链，需要联网与数 GB 空间。
首次较慢。只构建应用，不刷固件，不自动上传设备。
成功后更新 `sdcard/apps/Tools/novel_reader.fap`。
已有 SDK 版本不符或存在受跟踪修改时会停止，不会重置你的修改。

固件升级后如果提示 API mismatch，不要强行忽略兼容性检查；请使用对应版本重新编译。

## 真机测试清单

1. sample.txt 能否打开，中文是否完整且可读。
2. 上下翻页、左右跳页及边界处理是否正常。
3. 返回选书再打开，是否恢复原来的位置。
4. 退出应用、重新启动设备再打开，是否续读。
5. 切换常亮，等待超过系统原来的背光超时；再测试 Off 下按键是否亮灯。
6. 返回选书/退出应用，确认系统亮度恢复；重新进入确认设置记住了选择。
7. 长篇首次索引完成后退出再打开，比较第二次速度和续读位置。
8. 测试 Rebuild index 的进度显示、取消以及下一次自动恢复。

有问题请发屏幕照片、操作步骤、固件版本和小说的编码/大小。
